Parallel Streams

ForkJoinPool, when to use, and critical thread-safety pitfalls

A parallel stream splits source data into chunks processed concurrently by multiple threads using the shared ForkJoinPool.commonPool(). Results are then merged back. This can dramatically speed up CPU-intensive operations on large datasets.

Using Parallel Streams

Java — Parallel Stream Usage 
// Method 1: parallelStream() directly from collection
long sum = nums.parallelStream().mapToLong(Integer::intValue).sum();

// Method 2: .parallel() on existing stream
Stream<Integer> parallel = nums.stream().parallel();

// Check / toggle
parallel.isParallel();  // true
parallel.sequential(); // switch back to sequential

// Custom thread pool size (avoids blocking commonPool)
ForkJoinPool customPool = new ForkJoinPool(4);
customPool.submit(() ->
    nums.parallelStream().filter(n -> n%2==0).count()
).get();

When to Use vs Avoid Parallel Streams

✅ Good Candidates for Parallel

  • Large datasets (100,000+ elements)
  • CPU-intensive, independent computations
  • Stateless, side-effect-free operations
  • Data sources that split well (ArrayList, arrays)
  • No ordering requirement on output

❌ Bad Candidates for Parallel

  • Small datasets — overhead exceeds benefit
  • I/O-bound operations (DB calls, file reads)
  • Stateful operations requiring synchronization
  • LinkedList (hard to split efficiently)
  • Operations touching shared mutable state

Thread Safety — Race Conditions

Java — Thread Safety Examples 
// ❌ WRONG — ArrayList is NOT thread-safe
List<Integer> result = new ArrayList<>();
IntStream.range(0,1000).parallel().forEach(result::add);
// result.size() may be < 1000 — race condition!

// ✅ CORRECT 1 — use collect() (always thread-safe)
List<Integer> safe = IntStream.range(0,1000)
    .parallel().boxed().collect(Collectors.toList());

// ✅ CORRECT 2 — stateless operations are always safe
long count = IntStream.range(0,1000)
    .parallel().filter(n -> n%2==0).count(); // always 500 ✅

// ✅ CORRECT 3 — thread-safe accumulation with AtomicLong
AtomicLong atomicSum = new AtomicLong(0);
IntStream.range(0,1000).parallel().forEach(atomicSum::addAndGet);
