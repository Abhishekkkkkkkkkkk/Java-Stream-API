🟢 Easy Problems

P1: Sum of Even NumbersEasy

Given a list of integers, find the sum of all even numbers.

[1, 2, 3, 4, 5, 6, 7, 8]
20
Java 
int sum = List.of(1,2,3,4,5,6,7,8).stream()
    .filter(n -> n % 2 == 0)
    .mapToInt(Integer::intValue)
    .sum(); // 20

P4: Sum of Squares of Odd NumbersEasy
[1, 2, 3, 4, 5]
35 (1+9+25)
Java 
int sumSq = List.of(1,2,3,4,5).stream()
    .filter(n -> n % 2 != 0)
    .mapToInt(n -> n * n)
    .sum(); // 35

P10: Anagram GroupingHard

Group a list of strings so that anagrams are together.

["eat","tea","tan","ate","nat","bat"]
{aet=[eat,tea,ate], ant=[tan,nat], abt=[bat]}
Java 
Map<String,List<String>> anagrams = List.of("eat","tea","tan","ate","nat","bat")
    .stream()
    .collect(Collectors.groupingBy(w -> {
        char[] c = w.toCharArray();
        Arrays.sort(c);
        return new String(c); // sorted chars as canonical key
    }));

P12: Transpose a Matrix Using StreamsHard
Java 
int[][] matrix = {{1,2,3},{4,5,6},{7,8,9}};

int[][] transposed = IntStream.range(0, matrix[0].length)
    .mapToObj(col ->
        IntStream.range(0, matrix.length)
            .map(row -> matrix[row][col])
            .toArray())
    .toArray(int[][]::new);

P13: Custom Collector — Mean CalculationHard
Java — Custom Collector 
Collector<Integer,int[],Double> meanCollector = Collector.of(
    () -> new int[2],            // supplier: [sum, count]
    (arr, n) -> { arr[0]+=n; arr[1]++; }, // accumulator
    (a, b)   -> { a[0]+=b[0]; a[1]+=b[1]; return a; }, // combiner
    arr -> arr[1]==0 ? 0.0 : (double)arr[0]/arr[1] // finisher
);

double mean = Stream.of(1,2,3,4,5).collect(meanCollector); // 3.0
