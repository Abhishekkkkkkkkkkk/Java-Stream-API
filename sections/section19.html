🎯 Top 10 Interview Must-Know Points

🎯

Essential Points — Know These Cold

  • Streams are lazy — intermediate ops don't execute until a terminal op fires.
  • Streams are single-use — reusing a consumed stream throws IllegalStateException.
  • Filter before Map for performance — reduce elements first before expensive transforms.
  • collect() vs reduce() — mutable vs immutable reduction. Use collect for building containers.
  • findFirst() vs findAny() — deterministic vs non-deterministic in parallel.
  • orElse() vs orElseGet() — eager vs lazy evaluation of defaults. Use orElseGet for expensive defaults.
  • Parallel streams use ForkJoinPool. Avoid for small data, I/O, or shared mutable state.
  • flatMap() is the key to working with nested structures and Optional chaining.
  • Primitive streams (IntStream etc.) avoid boxing — always use for numeric work.
  • allMatch() on empty stream = true (vacuous truth) — a classic tricky question.
