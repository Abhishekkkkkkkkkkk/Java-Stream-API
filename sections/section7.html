Optional Class with Streams

Eliminating NullPointerException — safely handling absent values

Optional<T> is a container that may or may not hold a non-null value. Introduced in Java 8 to make null-safety explicit in the type system and eliminate the infamous NullPointerException.

Creating Optional Instances

Java — Creating Optionals 
// Optional.of() — throws NullPointerException if value is null
Optional<String> present = Optional.of("Java");       // ✅
Optional<String> danger  = Optional.of(null);         // ❌ NPE!

// Optional.ofNullable() — safe for potentially null values
Optional<String> safe1 = Optional.ofNullable("Java"); // present
Optional<String> safe2 = Optional.ofNullable(null);  // empty

// Optional.empty() — explicitly empty
Optional<String> empty = Optional.empty();

Using Optional — All Key Methods

Java — Optional API 
Optional<String> opt = Optional.of("Hello Java");

// Presence checks
opt.isPresent(); // true
opt.isEmpty();   // false (Java 11+)

// Execute only if present
opt.ifPresent(v -> System.out.println("Value: "+v));

// ifPresentOrElse (Java 9+)
opt.ifPresentOrElse(
    v -> System.out.println("Found: "+v),
    () -> System.out.println("Not found"));

// orElse — default (ALWAYS evaluated, even if value present!)
String v1 = opt.orElse("default"); // "Hello Java"

// orElseGet — lazy default (only evaluated if empty) ✅ prefer this!
String v2 = opt.orElseGet(() -> computeExpensiveDefault());

// orElseThrow — throw exception if absent
String v3 = opt.orElseThrow(() -> new RuntimeException("Not found"));

// map — transform value if present
Optional<Integer> len = opt.map(String::length); // Optional[10]

// filter — keep value only if condition met
Optional<String> filtered = opt.filter(s -> s.startsWith("H"));

// flatMap — avoids Optional<Optional<T>>
Optional<String> upper = opt.flatMap(s -> Optional.of(s.toUpperCase()));

// Chaining Optionals (avoid nested NPE checks)
String city = Optional.ofNullable(user)
    .map(User::getAddress)
    .map(Address::getCity)
    .orElse("Unknown");

Optional with Streams (Java 9+)

Java 
List<Optional<String>> opts = List.of(
    Optional.of("a"), Optional.empty(), Optional.of("b"), Optional.empty());

// Optional.stream() (Java 9) — filter out empties cleanly
List<String> present = opts.stream()
    .flatMap(Optional::stream)  // removes empties automatically
    .collect(Collectors.toList());
// ["a", "b"]

// Before Java 9 (verbose)
opts.stream()
    .filter(Optional::isPresent)
    .map(Optional::get)
    .collect(Collectors.toList());
⭐

Optional Best Practices

  • Use orElseGet() over orElse() for expensive defaults — orElse() always evaluates the argument.
  • Never call Optional.get() without checking first — use orElseThrow() for clarity.
  • Don't use Optional as a method parameter — only as a return type.
  • Don't use Optional for collection return types — return an empty collection instead.
  • Don't use Optional for primitive types — use OptionalInt, OptionalLong, OptionalDouble.
