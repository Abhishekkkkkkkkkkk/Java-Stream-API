8

Primitive Streams

IntStream, LongStream, DoubleStream — avoiding boxing overhead

Stream<Integer> boxes every int into an Integer heap object — causing object allocation, GC pressure, and cache misses. Primitive streams avoid this entirely.

Primitive Stream Equivalent Object Stream Extra Methods
IntStream Stream<Integer> sum(), min(), max(), average(), range(), rangeClosed(), summaryStatistics()
LongStream Stream<Long> sum(), min(), max(), average(), range(), rangeClosed()
DoubleStream Stream<Double> sum(), min(), max(), average()
Java — Primitive Streams 
// IntStream — sum 1..100 without boxing!
int sum = IntStream.rangeClosed(1,100).sum(); // 5050

// mapToInt() — convert Stream<T> to IntStream
int totalLen = Stream.of("Java","Streams","API").mapToInt(String::length).sum(); // 14

// boxed() — convert IntStream back to Stream<Integer>
Stream<Integer> boxed = IntStream.range(1,6).boxed();

// average() returns OptionalDouble
OptionalDouble avg = IntStream.of(1,2,3,4,5).average();
avg.ifPresent(System.out::println); // 3.0

// IntSummaryStatistics — all stats at once
IntSummaryStatistics stats = IntStream.of(10,20,30).summaryStatistics();
stats.getMax(); // 30
stats.getMin(); // 10
stats.getSum(); // 60
stats.getCount(); // 3
stats.getAverage(); // 20.0

// Widen type: asLongStream(), asDoubleStream()
LongStream   ls = IntStream.range(1,5).asLongStream();
DoubleStream ds = IntStream.range(1,5).asDoubleStream();

// Performance: primitive vs boxed sum of 10M elements
// LongStream.rangeClosed(1, 10_000_000).sum()  →  ~10ms  ✅
// Stream<Long> equivalently                   →  ~80ms  ❌ 8x slower!
